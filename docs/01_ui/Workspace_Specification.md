# Workspace Specification

Версия: 1.0

## Назначение

Workspace является главным экраном D-Control.

Пользователь проводит практически всю работу внутри Workspace.

Workspace не имеет отдельных страниц для различных функций. Меняется только содержимое рабочей области, а пользователь всегда остается внутри одного рабочего пространства.

Workspace объединяет навигацию, Kanban-доску, панель задачи, боковое меню, центр активности и поиск в единую рабочую среду.

Документ использует уже принятые решения проекта и соответствует `D-Control_Constitution.md`, `D-Control_UI_UX_Guidelines.md` и спецификациям компонентов.

## Структура Workspace

Workspace состоит из следующих компонентов:

- верхняя панель;
- рабочая область Kanban;
- панель задачи;
- боковое меню;
- центр активности;
- поиск.

Каждый компонент отвечает только за свою функцию.

Workspace не должен превращаться в набор отдельных страниц. Все представления открываются внутри общего рабочего пространства.

## Верхняя панель

Верхняя панель располагается по всей ширине окна.

Порядок элементов слева направо:

1. Кнопка открытия бокового меню `≡`.
2. Вкладки отделов.
3. Кнопка `+` для создания нового отдела.
4. Иконка `Избранное` `★`.
5. Центр активности `🔔`.
6. Глобальный поиск.
7. Кнопка открытия панели задачи.

### Кнопка бокового меню

Кнопка `≡` открывает боковое меню Workspace.

Кнопка должна быть компактной, визуально центрированной и не занимать лишнее место в верхней панели.

### Вкладки отделов

Каждая вкладка представляет отдельный отдел.

Каждый отдел имеет:

- собственную Kanban-доску;
- собственные колонки;
- собственные задачи;
- собственные настройки.

Переключение вкладки меняет только содержимое рабочей области. Workspace при этом не перезагружается и не меняет свою структуру.

### Кнопка `+`

Кнопка `+` используется для создания нового отдела.

Кнопка отображается только пользователям с соответствующими effective permissions.

Frontend не рассчитывает право на отображение кнопки самостоятельно. Он отображает действие только на основании данных backend.

### Избранное

Иконка `Избранное` `★` резервируется для будущего функционала.

Функциональность будет реализована позже без изменения базовой структуры Workspace.

### Центр активности

Иконка `🔔` открывает центр активности.

Рядом с иконкой может отображаться количество новых элементов, требующих внимания пользователя.

### Глобальный поиск

Глобальный поиск располагается у правого края верхней панели.

При открытии панели задачи поиск автоматически смещается влево и остается внутри доступной ширины Workspace.

После закрытия панели задачи поиск возвращается на исходное место.

### Кнопка открытия панели задачи

Кнопка открытия панели задачи располагается у самого правого края верхней панели.

Кнопка отображается только при закрытой панели задачи.

После открытия панели задачи кнопка исчезает. Закрытие панели выполняется только из самой панели задачи.

## Центр активности

Центр активности открывается по нажатию на иконку `🔔`.

Центр активности содержит быстрые переходы:

- входящие;
- сегодня;
- просроченные;
- ожидают закрытия;
- наблюдаю.

Каждый пункт открывает соответствующее представление Kanban-доски внутри Workspace.

Количество новых элементов отображается рядом с соответствующим пунктом.

Центр активности предназначен для быстрого перехода к задачам, требующим внимания пользователя. Он не заменяет Kanban и не является отдельной страницей.

## Рабочая область

Рабочая область представляет собой Kanban-доску.

Переключение между вкладками отделов изменяет только содержимое рабочей области.

Workspace при этом не изменяется.

Kanban используется только для:

- обзора задач;
- изменения расположения задач;
- открытия панели задачи;
- быстрых действий на карточке задачи.

Полноценная работа с задачей выполняется внутри панели задачи.

## Панель задачи

Панель задачи открывается поверх Workspace.

Панель задачи:

- перекрывает правую часть Kanban;
- перекрывает правую часть верхней панели;
- занимает всю высоту окна;
- может изменяться по ширине;
- остается открытой до тех пор, пока пользователь самостоятельно не закроет ее.

Workspace не меняет свои размеры как отдельная страница при открытии панели задачи, но верхняя панель и рабочая область должны визуально учитывать занятую панелью ширину, чтобы элементы не уходили под нее.

Панель задачи является главным рабочим пространством для выполнения работы с задачей.

## Боковое меню

Sidebar — левая навигационная панель Workspace.

Sidebar используется только для навигации и быстрого перехода к представлениям Workspace. Он не является отдельным экраном.

Правила поведения:

- ширина Sidebar — около 320 px;
- открывается поверх Workspace;
- не сдвигает Kanban;
- при открытии может затемнять рабочую область;
- закрывается по кнопке `✕`;
- закрывается по клику вне панели;
- закрывается после выбора пункта;
- в будущем можно добавить закрытие по Escape.

В верхней части Sidebar отображается профиль пользователя:

- аватар;
- имя;
- роль.

Аватарка кликабельна. В будущем клик по аватарке ведёт в настройки пользователя.

Основные пункты:

- Входящие;
- Сегодня;
- Просроченные;
- Ожидают закрытия;
- Наблюдаю.

Счётчики в Sidebar показывают новые элементы, а не общее количество.

Администрирование — свёрнутая секция. Секция отображается только при наличии прав.

Внутри секции:

- Пользователи;
- Отделы;
- Права доступа.

Нижний блок:

- Администрирование;
- Внешний вид;
- Настройки пользователя;
- Выход.

Активный пункт выделяется фоном и синей вертикальной полосой. Hover слабее active и одинаков для всех пунктов.

## Поиск

Поиск является глобальным.

Поиск осуществляется по:

- задачам;
- пользователям;
- отделам;
- комментариям;
- вложениям.

Список областей поиска может быть расширен в будущем.

Поиск не должен открывать отдельную страницу. Результаты поиска должны отображаться внутри Workspace или в связанном представлении, не разрушая рабочий контекст пользователя.

## Навигация

Workspace не использует отдельные страницы для базовой работы.

Все действия выполняются посредством:

- переключения вкладок;
- фильтрации;
- открытия панели задачи;
- открытия бокового меню;
- открытия центра активности;
- глобального поиска.

Пользователь никогда не должен ощущать, что покидает основное рабочее пространство.

## Основные принципы

Workspace является постоянным рабочим пространством пользователя.

Пользователь никогда не покидает Workspace во время обычной работы.

Kanban используется для навигации.

Карточка задачи используется для быстрого просмотра и быстрых действий.

Полноценная работа выполняется только внутри панели задачи.

Боковое меню используется только для навигации.

Центр активности используется для быстрого перехода к задачам, требующим внимания пользователя.

Frontend отображает интерфейс и effective permissions, а backend принимает бизнес-решения.

## Будущие расширения

Архитектура Workspace должна позволять без изменения существующей структуры добавлять новые возможности.

Возможные будущие расширения:

- избранное;
- календарь;
- табличное представление;
- диаграмма Ганта;
- дополнительные пользовательские панели;
- новые представления задач;
- дополнительные фильтры центра активности;
- расширенные результаты глобального поиска.

Новые функции должны интегрироваться в существующую архитектуру Workspace и не нарушать основные принципы проекта.

Если новая функция противоречит Конституции проекта, сначала должна быть изменена Конституция, а только затем реализация и спецификации.
