# Task Card Specification

## Назначение карточки

Карточка предназначена для быстрого просмотра задачи и выполнения наиболее частых действий без открытия панели задачи.

Полноценная работа выполняется внутри панели задачи.

## Связь с Workspace

Карточка задачи является компонентом Workspace.

Карточка располагается внутри рабочей области Workspace — Kanban-доски.

Карточка используется для быстрого просмотра информации и выполнения быстрых действий.

Полноценная работа выполняется в панели задачи.

Карточка не является самостоятельным экраном.

## Структура карточки

### Верхняя часть

- Кнопка `⋯`.

### Центральная часть

- Название задачи.
- Исполнитель, если назначен.
- Срок, если установлен.
- Индикаторы, при необходимости.

### Нижняя часть

- Кнопка `+`.

## Быстрые действия

При наведении курсора на кнопку `+` появляется панель:

- 👤 Исполнитель
- 📅 Срок
- 🔥 Приоритет
- ➕ Подзадача

При клике по `+` панель закрепляется.

## Контекстное меню

Кнопка `⋯` открывает контекстное меню.

Содержит:

- Редактировать задачу.
- Назначить наблюдателя.
- Вернуть на доработку.
- Удалить.

Список меню зависит от effective permissions пользователя, рассчитанных backend.

Frontend не должен самостоятельно определять бизнес-права. Он отображает только действия, полученные от backend.

## Принципы

Карточка должна оставаться максимально компактной.

Пользователь должен иметь возможность выполнить наиболее частые действия, не открывая панель задачи.

Редкие действия размещаются в контекстном меню.

Права пользователя определяют отображаемые действия.

## Поведение

Наведение курсора

↓

Показывает быстрые действия.

Клик по карточке

↓

Открывает панель задачи.

Клик по `+`

↓

Закрепляет панель быстрых действий.

Клик по `⋯`

↓

Открывает контекстное меню.

## Будущие расширения

Этот раздел предназначен для будущих возможностей карточки задачи без изменения общей архитектуры.

Возможные направления расширения:

- отображение unread-индикаторов;
- быстрые признаки просрочки;
- компактные маркеры блокировки или ожидания;
- preview последнего сообщения;
- поддержка keyboard shortcuts;
- адаптация карточки под разные плотности интерфейса.
