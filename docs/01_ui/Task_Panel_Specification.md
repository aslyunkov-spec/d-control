# Task Panel Specification

## Назначение панели

Панель задачи является главным рабочим пространством для полноценной работы с выбранной задачей.

Kanban используется для навигации и открытия задачи, а работа с задачей выполняется внутри панели.

## Связь с Workspace

Панель задачи открывается поверх Workspace.

Панель перекрывает Kanban.

Панель перекрывает верхнюю панель.

Workspace не изменяет свои размеры при открытии панели.

После закрытия панели пользователь возвращается к тому же состоянию Workspace.

## Базовое поведение

Панель остается открытой до тех пор, пока пользователь самостоятельно не закроет ее.

Панель не является отдельной страницей.

Панель не должна разрушать рабочий контекст Workspace.

## Размеры

Панель задачи поддерживает изменение ширины.

Базовые размеры задаются документацией UI/UX:

- минимум: 350 px;
- по умолчанию: 450 px;
- максимум: 900 px.

## Принципы

Панель задачи предназначена для выполнения работы, а не только для просмотра информации.

Frontend отображает доступные действия, рассчитанные backend.

Пользователь выполняет действия, а не изменяет статусы напрямую.
