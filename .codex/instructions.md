# D-Control Development Rules

Перед внесением изменений:

1. Сначала покажи краткий план.
2. Не изменяй models.py без необходимости.
3. Не создавай миграции без необходимости.
4. Если требуется миграция — сначала объясни зачем.
5. Изменяй минимально необходимое количество файлов.
6. После каждого изменения выполняй:

   * python manage.py check
   * python manage.py makemigrations --check --dry-run
7. Показывай:

   * список изменённых файлов;
   * список созданных файлов;
   * необходимость миграций.
8. Не изменяй архитектуру проекта без объяснения.
9. Предпочитай стандартные возможности Django и DRF.
10. Для крупных задач сначала делай анализ и план, потом изменения.
